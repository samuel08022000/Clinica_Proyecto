Capítulo 8 · Ejercicio 1

1. Ordenamos la parte de segundo orden como A uₓₓ + 2B uₓᵧ + C uᵧᵧ. Calculamos D=B²−AC. Con variables x,t se leen los coeficientes de uₓₓ, uₓₜ y uₜₜ.

a) (1−M²)φₓₓ+φᵧᵧ=0. A=1−M², B=0, C=1. Entonces D=M²−1. Para flujo subsónico, 0≤M<1, resulta D<0: elíptica. Aplicamos diferencias centrales y resolvemos el sistema con Gauss–Seidel. Para M=1 es parabólica y para M>1 es hiperbólica.

b) uₜ=νuₓₓ. Escribimos νuₓₓ−uₜ=0. A=ν, B=C=0, luego D=0: parabólica. Se puede usar Crank–Nicolson con condición inicial y condiciones de frontera.

c) (x²−1)uₓₓ+2yuₓᵧ−uᵧᵧ=0. A=x²−1, B=y, C=−1. D=y²−(x²−1)(−1)=x²+y²−1. Dentro del círculo unitario D<0: elíptica (diferencias centrales). Sobre la circunferencia D=0: parabólica en la clasificación puntual. Fuera del círculo D>0: hiperbólica (características). En todo el plano es de tipo mixto.

d) φₓₓ+φᵧᵧ=−c/ν. A=C=1 y B=0, así D=−1: elíptica. Se usa la fórmula de Poisson de cinco puntos y se resuelve el sistema con los datos de frontera.

e) −aTₓₓ+bTₓ+cT+Tₜ=0. A=−a, B=C=0, por lo que D=0: parabólica. Escribimos Tₜ=aTₓₓ−bTₓ−cT y avanzamos en el tiempo con Crank–Nicolson.

Apéndice · Programas para los ejercicios computacionales

Python 3. El primer programa imprime todas las iteraciones, incluidos los puntos intermedios de las mallas finas. Cada fila contiene x, solución numérica, solución exacta y error verdadero.

from math import exp, log, tan

def resolver(f, exacta, a, b, y, h, metodo):
    for i in range(round((b-a)/h) + 1):
        x = a+i*h
        print(x, y, exacta(x), exacta(x)-y)
        if i == round((b-a)/h):
            break
        k1 = f(x,y)
        if metodo == "Euler":
            y += h*k1
        else:
            k2 = f(x+h/2, y+h*k1/2)
            k3 = f(x+h/2, y+h*k2/2)
            k4 = f(x+h, y+h*k3)
            y += h*(k1+2*k2+2*k3+k4)/6

Capítulo 8 · Ejercicios 3 y 4

La matriz usa filas para y y columnas para x. La sobrerrelajación acelera la convergencia sin cambiar la ecuación de los cuatro vecinos.

import numpy as np

for ejercicio, nx in [(3,100),(4,200)]:
    ny = 100
    x = np.arange(nx+1)*0.01
    y = np.arange(ny+1)*0.01
    u = np.zeros((ny+1,nx+1))
    if ejercicio == 3:
        u[-1,:] = x
        u[:,-1] = y
        exacta = y[:,None]*x
    else:
        u[-1,:] = np.sin(np.pi*x/2)
        u[-1,-1] = 0
        exacta = (np.sinh(np.pi*y[:,None]/2)/np.sinh(np.pi/2)
                  * np.sin(np.pi*x/2))
    # Gauss-Seidel en dos colores con sobrerrelajación.
    interior = u[1:-1,1:-1]
    j,i = np.indices(interior.shape)
    mascaras = [(i+j)%2 == c for c in (0,1)]
    for vuelta in range(100000):
        cambio = 0
        for mascara in mascaras:
            media = (u[:-2,1:-1]+u[2:,1:-1]+u[1:-1,:-2]+u[1:-1,2:])/4
            delta = 1.9*(media[mascara]-interior[mascara])
            interior[mascara] += delta
            cambio = max(cambio,np.max(np.abs(delta)))
        if cambio < 1e-13:
            break
    else:
        raise RuntimeError("No se alcanzó la tolerancia")
    print(ejercicio, vuelta+1, np.max(np.abs(u-exacta)))
    print("Centro:",u[ny//2,nx//2],exacta[ny//2,nx//2])
